# Website Admin acceptance checklist

- [ ] Edit website opens the visual editor
- [ ] Clicking text allows editing
- [ ] Clicking an image allows replacement
- [ ] Product pages are manageable from Admin
- [ ] Desktop/tablet/mobile preview
- [ ] Undo / redo
- [ ] Save draft
- [ ] Publish changes
- [ ] SEO title, description and page slug controls
- [ ] English / French / Spanish / Farsi content support
- [ ] Farsi RTL support
- [ ] No layout overlap on mobile
- [ ] Existing public website remains usable if Admin/editor is unavailable
- [ ] Production credentials are never exposed to client-side code
