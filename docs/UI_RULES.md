# Website Admin / Builder — UI rules

- Light neutral backgrounds
- Strong typography and clear hierarchy
- Consistent global navigation and controls
- Large clean imagery
- Minimal accent colours
- No overlapping text or controls
- Mobile-first responsive behavior
- Reusable components and an 8px spacing system
- Keyboard-accessible forms and visible focus states
- Website edits must preserve SEO structure and page semantics

## Editor behavior
- Text elements should be directly editable.
- Images should be replaceable from the editor.
- Product content and pricing fields should be manageable from Admin.
- Changes should have safe Save/Publish behavior.
- Undo/redo should be supported where practical.
- Section-level editing should not require editing raw HTML/CSS.
