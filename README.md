# Satin Graphic — Website Admin / Builder

Admin and website-editing project for Satin Graphic.

## Goal
Provide a Wix-like editing experience for the Satin Graphic website:
- click text and edit it directly
- click an image and replace it
- manage products and product content
- edit sections without touching code
- keep responsive desktop/mobile layouts
- preserve strong SEO
- support English, French, Spanish and Farsi

## Source status
The production website source is stored in the private repository:
https://github.com/Mehrad-zb/satin-graphic-website

This repository preserves the Website Admin / Builder requirements and handoff material separately. The latest standalone editor source was not available as an independent source archive when this repository was initialized, so no fake or reconstructed editor code has been committed here.

## Design direction
Light, premium UI inspired by Apple/Tesla discipline, with readable system-style typography and the Satin admin visual language.

## Security
Do not commit production passwords, API keys, database credentials, customer uploads, or private order data.
